# BasketAI — MVP inicial

Este é o primeiro protótipo responsivo do BasketAI, pensado para funcionar em navegador de computador e celular.

## O que já funciona
- Interface adaptável para telas grandes e pequenas.
- Alternância entre NBA e WNBA.
- Cartões demonstrativos de jogos.
- Tabela demonstrativa de Player Props.

## Atenção
Os jogos, equipes, atletas, linhas e probabilidades são dados fictícios de demonstração. Não são previsões nem recomendações de apostas.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. No celular, você também pode abrir o endereço publicado quando fizermos a hospedagem.

## Próxima etapa
Conectar uma fonte de dados licenciada e adequada para NBA/WNBA, criar banco de dados e substituir os exemplos por dados reais. Antes de contratar qualquer API, vamos testar limites gratuitos, cobertura, atualização e permissão de uso comercial.

## Publicação gratuita (próxima fase)
Podemos publicar o protótipo usando um serviço com plano gratuito, como GitHub Pages ou Netlify. Para atualizações futuras, o projeto será evoluído para uma arquitetura com backend e banco de dados.
